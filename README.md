# Odin Recipes 🍳

## Description

A multi-page recipe web application built as part of **The Odin Project** Foundations curriculum. This project demonstrates strong foundations in core HTML5 semantics, relative pathing across nested directories, command-line usage, and clean Git version control workflows prior to applying CSS styling.

---

## 📸 Overview & Structure

The application features a central home page linking to standalone recipe pages with dish previews, detailed ingredient lists, and step-by-step preparation guides.

```text
odin-recipes/
├── index.html
├── README.md
├── images/
│   ├── chicken-karahi.jpg
│   ├── paratha.jpg
│   └── rasmalai.jpg
└── recipes/
    ├── chicken-karahi.html
    ├── paratha.html
    └── rasmalai.html

---

## 🛠️ Skills Demonstrated

- Working with HTML boilerplate structure

- Creating headings, paragraphs, and lists (ordered and unordered)

- Linking pages together with anchor tags (<a>)

- Adding and embedding images

- Managing files and folders within a Git repository

- Using CLI to make directories, files, and renaming files
